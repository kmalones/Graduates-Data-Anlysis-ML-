# Graduates Data Analysis (ML)

This repository contains a Jupyter Notebook for basic analysis of graduate data using Python and pandas.

## Repository contents

- `Graduates.ipynb` — notebook with data loading and initial exploration steps
- `README.md` — project documentation

## Requirements

- Python 3.10+ (any recent Python 3 version should work)
- Jupyter Notebook or JupyterLab
- `pandas`

Install dependencies:

```bash
pip install pandas notebook
```

## How to run

1. Place your dataset file in the repository root as `graduates.csv`.
2. Start Jupyter:

```bash
jupyter notebook
```

3. Open `Graduates.ipynb` and run the cells in order.

## Notes

- The notebook currently includes early exploratory steps and may need cleanup/refinement as analysis evolves.
- If you want reproducible environments, consider adding a `requirements.txt` file later.
